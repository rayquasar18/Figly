**frontend/src/hooks/queries/interaction-queries.ts** -- Optimistic like/bookmark mutations:
- `useLikeMutation()`: POST /posts/:id/like. onMutate: cancel feed/post queries, snapshot, optimistically set isLiked=true and likeCount+1 across ALL matching query keys using `setQueriesData` with predicate (feed pages, post detail, user posts). onError: rollback. onSettled: invalidate. Follow 03-RESEARCH.md Pattern 3 exactly.
- `useUnlikeMutation()`: DELETE /posts/:id/like. Same pattern, set isLiked=false and likeCount-1.
- `useBookmarkMutation()`: POST /posts/:id/bookmark. Same optimistic pattern for isBookmarked.
- `useUnbookmarkMutation()`: DELETE /posts/:id/bookmark. Same pattern.
- `useUpdateCaption()`: PATCH /posts/:id with { caption }. Invalidate post queries on success.
- `useDeletePost()`: DELETE /posts/:id. Invalidate feed and user posts on success. Show success toast.
