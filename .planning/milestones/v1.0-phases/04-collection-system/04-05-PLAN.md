    **Checklist Query Hooks (frontend/src/hooks/queries/checklist-queries.ts):**
    - `useMyChecklists()`: useQuery GET /checklists -- returns user's checklists with counts
    - `useChecklistDetail(checklistId)`: useQuery GET /checklists/:id -- returns checklist with entries
    - `useCreateChecklist()`: useMutation POST /checklists -- invalidates checklists list on success
    - `useUpdateChecklist()`: useMutation PATCH /checklists/:id -- invalidates checklist detail + list
    - `useDeleteChecklist()`: useMutation DELETE /checklists/:id -- invalidates list, navigate to /checklists
    - `useAddEntry()`: useMutation POST /checklists/:id/entries -- invalidates checklist detail
    - `useToggleEntry()`: useMutation PATCH /checklists/entries/:id/toggle -- optimistic update on isChecked + progress counts
    - `useRemoveEntry()`: useMutation DELETE /checklists/entries/:id -- invalidates checklist detail
    - `useReorderEntries()`: useMutation PATCH /checklists/:id/reorder -- optimistic update on entry positions

    Toggle entry uses optimistic update: flip isChecked in cache, update totalEntries/checkedEntries counts.
