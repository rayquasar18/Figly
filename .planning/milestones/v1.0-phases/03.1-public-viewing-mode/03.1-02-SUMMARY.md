## Decisions Made
- Moved [username] and post routes from (app) to (public) to avoid Next.js route conflicts (both groups resolve to same URL paths)
- Public layout calls useMe() but does not redirect on failure -- null user means unauthenticated browsing is allowed
- API client interceptor fix targets only /auth/me endpoint 401s (simplest correct fix since public endpoints use OptionalJwtAuthGuard and never return 401)
- requireAuth pattern wraps individual click handlers rather than disabling buttons -- keeps visual affordance while redirecting on interaction
- CommentInput renders a styled Link to /login with "Dang nhap de binh luan" text instead of the comment form for unauthenticated users
- PublicNav uses user.name for avatar fallback since PublicUser type has no avatarUrl field
