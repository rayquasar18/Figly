**OptionalJwtAuthGuard with null-safe viewerId pattern enabling unauthenticated read access to profiles, posts, comments, followers, and a public discovery feed**

## Accomplishments
- Created OptionalJwtAuthGuard that allows unauthenticated requests through with req.user=null
- Refactored all read endpoints (6 controllers) to use optional auth while keeping write endpoints strictly protected
- Added GET /feed/public endpoint for public discovery feed with chronological ordering
- All services accept nullable viewerId, skipping interaction queries when unauthenticated (performance optimization)
- 22 new tests covering public access behavior, guard logic, and public feed

## Decisions Made
- OptionalJwtAuthGuard overrides `handleRequest` to return `user || null` -- standard NestJS optional auth pattern
- Skip like/bookmark/follow queries entirely when viewerId is null rather than passing empty strings -- avoids unnecessary DB queries
- GET /feed/public has no guard at all (not even OptionalJwtAuthGuard) since viewer identity is never used for public feed
- Extracted `mapPostResponse` helper in FeedService for code reuse between personal and public feed
