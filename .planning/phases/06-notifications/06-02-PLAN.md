  <action>
    1. **Zustand notification store** (`notification-store.ts`):
       - State: `unreadCount: number`, `sseConnected: boolean`
       - Actions: `setUnreadCount(n)`, `incrementUnread()`, `decrementUnread()`, `resetUnread()`, `setSseConnected(bool)`
       - Pattern: follow auth-store.ts structure with create + selectors

    2. **SSE hook** (`use-sse.ts`):
       - `useSSE(enabled: boolean)`: when enabled, create EventSource to `${API_URL}/notifications/stream` with `withCredentials: true`
       - On `message` event: parse JSON as NotificationResponse, call `incrementUnread()` on store, call `queryClient.invalidateQueries({ queryKey: ['notifications'] })` for background refetch
       - On `error`: close EventSource, set sseConnected=false, setTimeout 30s then reconnect (polling fallback per user decision)
       - On `open`: set sseConnected=true
       - Cleanup on unmount: close EventSource
       - Use `useRef` for EventSource to prevent stale closures
       - API_URL from `process.env.NEXT_PUBLIC_API_URL || 'http://localhost:4000/api'`

    3. **TanStack Query hooks** (`notification-queries.ts`):
       - `useNotifications(cursor?)`: useInfiniteQuery to GET /notifications with cursor pagination. queryKey: ['notifications']. getNextPageParam from response.nextCursor. Select: flatten pages into single array
       - `useUnreadCount()`: useQuery to GET /notifications/unread-count. queryKey: ['notifications', 'unread-count']. On success, sync to notification store via `setUnreadCount(data.count)`. refetchInterval: 60000 (1 min background poll as safety net)
       - `useMarkAsRead()`: useMutation to PATCH /notifications/:id/read. On success: update notification in cache to isRead=true, call store.decrementUnread(). Optimistic update: set isRead=true in cache immediately
       - `useMarkAllAsRead()`: useMutation to PATCH /notifications/read-all. On success: invalidate notifications query, call store.resetUnread(). Optimistic update: set all isRead=true in cache
       - `useSavePushSubscription()`: useMutation to POST /notifications/push-subscription
       - `useRemovePushSubscription()`: useMutation to DELETE /notifications/push-subscription

    4. **Push permission hook** (`use-push-permission.ts`):
       - Track session count in localStorage key `figly_sessions`. Increment on mount
       - Only proceed after 2+ sessions (sessionCount >= 1 since 0-indexed)
       - Check: 'serviceWorker' in navigator AND 'PushManager' in window AND Notification.permission !== 'denied'
       - If subscription already exists (registration.pushManager.getSubscription()), send to backend via useSavePushSubscription
       - If no subscription and permission === 'default': return `{ canPrompt: true, requestPermission }` for UI to show custom prompt
       - If permission === 'granted': auto-subscribe with VAPID public key from NEXT_PUBLIC_VAPID_PUBLIC_KEY env var, send to backend
       - `requestPermission()`: call Notification.requestPermission(). If granted, subscribe and send to backend
       - Helper: `urlBase64ToUint8Array(base64String)` for VAPID key conversion
       - Helper: `arrayBufferToBase64(buffer)` for subscription key serialization

    5. **PWA manifest** (`frontend/public/manifest.json`):
