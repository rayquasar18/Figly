  <action>
1. Install jose in the frontend package:
   ```
   cd frontend && pnpm add jose
   ```

2. Create `frontend/src/proxy.ts` (Next.js 16 proxy convention, replaces deprecated middleware.ts):
   - Export async function `proxy(request: NextRequest)` (NOT `middleware`)
   - Export `config` with matcher: `'/((?!api|_next/static|_next/image|favicon.ico|sitemap.xml|robots.txt).*)'`
   - Define `PROTECTED_ROUTES = ['/', '/reels', '/saved', '/checklists', '/complete-profile']` per D-10
   - Function `isProtectedRoute(pathname)`: return true if pathname matches or starts with any protected route
   - For non-protected routes: return `NextResponse.next()`
   - For protected routes:
     a. Read `access_token` and `refresh_token` from `request.cookies`
     b. If neither exists: `NextResponse.redirect(new URL('/login', request.url))`
     c. If access_token exists: try `jwtVerify(accessToken, new TextEncoder().encode(process.env.JWT_SECRET))` -- if valid return `NextResponse.next()`; if throws, fall through
     d. If refresh_token exists (but access_token expired/missing): return `NextResponse.next()` (client interceptor handles refresh)
     e. Otherwise: redirect to `/login`
   - Import `jwtVerify` from `jose`, `NextResponse` and `NextRequest` from `next/server`
   - Per D-12: NO backend API calls -- purely cookie + JWT decode

3. Create `frontend/src/lib/server-fetch.ts`:
   - Import `cookies` from `next/headers`
   - Define `const API_URL = process.env.NEXT_PUBLIC_API_URL || 'http://localhost:4000/api'`
   - Export async function `fetchApi<T>(path: string, options?: RequestInit): Promise<T | null>`
   - Inside: `const cookieStore = await cookies()` (async in Next.js 16)
   - Get `access_token` from cookieStore
   - Build headers with `Content-Type: application/json` and cookie forwarding: `Cookie: access_token=${accessToken}` if token exists
   - `fetch(API_URL + path, { ...options, headers, cache: 'no-store' })`
   - Return `null` on non-ok response or catch error
   - Return `res.json() as Promise<T>` on success

4. Update `frontend/tailwind.config.ts`:
   - Add `'./src/features/**/*.{ts,tsx}'` to the `content` array (between components and app entries)
   - Keep all existing content entries unchanged
