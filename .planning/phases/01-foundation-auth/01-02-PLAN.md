  <action>
    Install auth dependencies in backend: `pnpm add @nestjs/passport @nestjs/jwt passport passport-jwt passport-local argon2 class-validator class-transformer`. DevDeps: `pnpm add -D @types/passport-jwt @types/passport-local`.

    1. **backend/src/auth/dto/auth.dto.ts**: NestJS DTOs using class-validator decorators for backend validation (mirrors Zod schemas from shared package). SignupDto (email: @IsEmail, password: @MinLength(8) + custom validators for letters/numbers, name: @IsNotEmpty). LoginDto (email, password). Vietnamese error messages in decorator options.

    2. **backend/src/auth/auth.service.ts**: Injectable service with PrismaService, JwtService, ConfigService.
       - `signup(dto)`: Check email uniqueness (throw ConflictException if exists). Hash password with argon2.hash(). Create user with emailVerified: false. Return user (do NOT auto-login -- must verify email first).
       - `validateUser(email, password)`: Find user by email (throw UnauthorizedException "Email khong ton tai" if not found). Compare password with argon2.verify() (throw UnauthorizedException "Sai mat khau" if mismatch). Check emailVerified (throw ForbiddenException "Email chua duoc xac minh" if false). Return user.
       - `login(user, userAgent)`: Generate access token (15min, payload: sub+email) and refresh token (30d, payload: sub+tokenFamily). Hash refresh token with argon2, store in RefreshToken table with userId, userAgent, expiresAt. Return TokenPair.
       - `refreshTokens(userId, refreshToken, userAgent)`: Find user's refresh tokens. Verify the provided token against stored hashes. If valid, delete old token, create new token pair (rotation). If invalid (possibly stolen), delete ALL user's refresh tokens for that device (security measure). Return new TokenPair.
       - `logout(userId, refreshToken)`: Delete the matching refresh token from DB. Do NOT clear all sessions (multi-device support).
       - `setCookies(res, tokens)`: Set access_token cookie (httpOnly, secure in prod, sameSite: strict, maxAge: 15min, path: /). Set refresh_token cookie (same security, maxAge: 30d, path: /api/auth/refresh).
       - `clearCookies(res)`: Clear both cookies.

    3. **backend/src/auth/strategies/local.strategy.ts**: PassportStrategy(Strategy, 'local'). usernameField: 'email'. validate() calls authService.validateUser().

    4. **backend/src/auth/strategies/jwt.strategy.ts**: PassportStrategy(Strategy, 'jwt'). Extract token from cookie (req.cookies.access_token). Validate by returning { userId: payload.sub, email: payload.email }.

    5. **backend/src/auth/strategies/jwt-refresh.strategy.ts**: PassportStrategy(Strategy, 'jwt-refresh'). Extract from cookie (req.cookies.refresh_token). Pass the raw refresh token along in the validated payload for rotation check.

    6. **Guards**: JwtAuthGuard extends AuthGuard('jwt'). LocalAuthGuard extends AuthGuard('local'). EmailVerifiedGuard checks request.user.emailVerified, throws ForbiddenException if false.

    7. **backend/src/auth/auth.controller.ts**: All endpoints under /auth prefix.
       - `POST /auth/signup`: Validate body (SignupDto), call authService.signup(), trigger email verification (Task 2), return 201 { message: "Dang ky thanh cong. Vui long kiem tra email de xac minh." }.
       - `POST /auth/login`: Use LocalAuthGuard, call authService.login(), set cookies, return 200 { user }.
       - `POST /auth/refresh`: Use JwtRefreshGuard, call authService.refreshTokens(), set new cookies, return 200.
       - `POST /auth/logout`: Use JwtAuthGuard, call authService.logout(), clear cookies, return 200.
       - `GET /auth/me`: Use JwtAuthGuard + EmailVerifiedGuard, return current user.
       - Apply @Throttle({ login: { ttl: 60000, limit: 5 } }) on login endpoint.

    8. **backend/src/auth/auth.module.ts**: Register AuthService, all strategies, all guards. Import PassportModule, JwtModule.registerAsync (using ConfigService for secret), PrismaModule, EmailModule (from Task 2 -- wire later). Export AuthService, JwtAuthGuard.
