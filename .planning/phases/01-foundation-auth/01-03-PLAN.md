Build the complete frontend authentication UI (login, signup, email verification, password reset, OAuth buttons) with silent token refresh, plus the backend async media processing pipeline (MinIO upload, BullMQ worker, Sharp thumbnails).   <behavior>
    - Upload endpoint accepts multipart file (image), validates type and size (<=10MB)
    - File is stored in MinIO under originals/{userId}/{uuid}-{filename}
    - DB Media record created with status PROCESSING
    - BullMQ job queued for async processing
    - Worker downloads original, generates 3 sizes (150px, 600px, 1080px) as WebP
    - Variants stored in MinIO under thumbnail/, medium/, large/ prefixes
    - DB updated with variant keys and status COMPLETED
    - GET /media/:id returns media record with presigned URLs for all variants
    - Upload of file >10MB returns 413
    - Upload of non-image file returns 400
    - Failed processing sets status to FAILED
  </behavior>
  <action>
    Install in backend: `pnpm add @nestjs/bullmq bullmq @aws-sdk/client-s3 @aws-sdk/s3-request-presigner sharp multer`. DevDep: `pnpm add -D @types/multer`.

    1. **backend/src/media/storage.service.ts**: Injectable. S3Client configured for MinIO (endpoint from config, forcePathStyle: true, region: us-east-1). Methods:
       - `upload(key, buffer, contentType)`: PutObjectCommand to MINIO_BUCKET.
       - `download(key)`: GetObjectCommand, return Buffer.
       - `getPresignedUrl(key, expiresIn=3600)`: getSignedUrl from @aws-sdk/s3-request-presigner.
       - `onModuleInit()`: CreateBucketCommand if bucket doesn't exist (catch BucketAlreadyOwnedByYou).

    2. **backend/src/media/media.service.ts**: Injectable. Inject PrismaService, StorageService, @InjectQueue('media-processing') Queue.
       - `upload(file, userId)`: Validate mimetype starts with 'image/' (throw BadRequestException otherwise). Validate size <= FILE_LIMITS.image (throw PayloadTooLargeException otherwise). Generate key: `originals/${userId}/${randomUUID()}-${file.originalname}`. Upload to MinIO. Create Media record (status: PROCESSING). Add job to queue: { mediaId, originalKey, userId }. Return media record.
       - `getMedia(mediaId, userId)`: Find media by id. Verify userId matches. Generate presigned URLs for all non-null keys. Return media with URLs.
       - `getMediaStatus(mediaId)`: Return status field only (for polling).

    3. **backend/src/media/media.processor.ts**: @Processor('media-processing'). Extends WorkerHost.
       - `process(job)`: Download original from MinIO. For each THUMBNAIL_SIZES (from shared constants): resize with Sharp (width, withoutEnlargement: true), convert to WebP (quality: 80), upload variant to MinIO (replace 'originals/' with '{size.name}/'). Update Media record: set thumbnailKey, mediumKey, largeKey, status: COMPLETED. Wrap in try/catch: on error, set status: FAILED, log error.

    4. **backend/src/media/media.controller.ts**: Prefix: 'media'. All routes use JwtAuthGuard + EmailVerifiedGuard.
       - `POST /media/upload`: @UseInterceptors(FileInterceptor('file')). Call mediaService.upload(). Return 201 { media }.
       - `GET /media/:id`: Call mediaService.getMedia(). Return 200 { media, urls }.
       - `GET /media/:id/status`: Call mediaService.getMediaStatus(). Return 200 { status }.

    5. **backend/src/media/media.module.ts**: Import BullModule.registerQueue({ name: 'media-processing' }). Register MediaService, MediaProcessor, StorageService, MediaController. Import BullModule.forRoot({ connection: { host, port } }) in AppModule (or use config).

    6. **Update backend/src/app.module.ts**: Import BullModule.forRootAsync (using ConfigService for Redis connection), MediaModule.

    7. **Test file -- backend/src/media/__tests__/media.spec.ts**: Test upload validation (size limit, mimetype check), test job queuing, test processor (mock Sharp and StorageService). Test presigned URL generation.
