  </files>
  <behavior>
    - createChecklist(userId, { name, isPublic }): creates checklist, returns ChecklistResponse
    - getMyChecklists(userId): returns user's checklists with totalEntries/checkedEntries counts
    - getChecklistDetail(checklistId, userId): returns checklist with entries ordered by position, verifies ownership or isPublic
    - getPublicChecklists(username): returns public checklists for profile showcase
    - updateChecklist(checklistId, userId, updates): update name/isPublic, verify ownership
    - deleteChecklist(checklistId, userId): delete with ownership check
    - addEntry(checklistId, userId, { itemId?, freeformText? }): add entry at end (max position + 1)
    - toggleEntry(entryId, userId): toggle isChecked, verify ownership via checklist
    - removeEntry(entryId, userId): delete entry, verify ownership
    - reorderEntries(checklistId, userId, entryIds): set position based on array index order
  </behavior>
  <action>
    **ChecklistService (backend/src/checklist/checklist.service.ts):**
    1. `createChecklist(userId, dto)`: prisma.checklist.create with userId, return with counts (0/0)
    2. `getMyChecklists(userId)`: findMany where userId, include _count and aggregated checked count. For checked count, use raw count or include entries with isChecked=true count.
    3. `getChecklistDetail(checklistId, viewerId)`: findUnique with entries ordered by position. If not owner and not isPublic, throw ForbiddenException.
    4. `getPublicChecklists(username)`: find user by username, findMany checklists where userId and isPublic=true, with entry counts.
    5. `updateChecklist(id, userId, dto)`: findFirst to verify ownership, then update.
    6. `deleteChecklist(id, userId)`: findFirst to verify ownership, then delete (cascade deletes entries).
    7. `addEntry(checklistId, userId, dto)`: verify checklist ownership. Find max position among existing entries, create at position+1. If itemId provided, verify item exists.
    8. `toggleEntry(entryId, userId)`: find entry with checklist include, verify ownership, update isChecked to !isChecked.
    9. `removeEntry(entryId, userId)`: find with checklist, verify ownership, delete.
    10. `reorderEntries(checklistId, userId, entryIds)`: verify ownership, then update each entry's position to its array index. Use $transaction for atomicity.

    **ChecklistController (backend/src/checklist/checklist.controller.ts):**
    Route prefix: `@Controller('checklists')`. All endpoints require JwtAuthGuard except getPublicChecklists.
    - `POST /checklists` -- createChecklist
    - `GET /checklists` -- getMyChecklists (current user)
    - `GET /checklists/:id` -- getChecklistDetail
    - `PATCH /checklists/:id` -- updateChecklist
    - `DELETE /checklists/:id` -- deleteChecklist
    - `POST /checklists/:id/entries` -- addEntry
    - `PATCH /checklists/entries/:entryId/toggle` -- toggleEntry
    - `DELETE /checklists/entries/:entryId` -- removeEntry
    - `PATCH /checklists/:id/reorder` -- reorderEntries
    - `GET /checklists/users/:username` -- OptionalJwtAuthGuard -- getPublicChecklists

    **DTO (backend/src/checklist/dto/checklist.dto.ts):**
    Import shared schemas, create class-validator wrappers.

    **Module (backend/src/checklist/checklist.module.ts):**
    Standard NestJS module. Register in AppModule.

    **Tests (backend/src/checklist/__tests__/checklist.service.spec.ts):**
    - createChecklist creates and returns with 0/0 counts
    - getMyChecklists returns only user's checklists
    - getChecklistDetail returns entries; throws Forbidden for non-owner on private checklist
    - addEntry adds at correct position; validates item exists for itemId entries
    - toggleEntry flips isChecked
    - removeEntry deletes entry
    - reorderEntries sets correct positions
  </action>
