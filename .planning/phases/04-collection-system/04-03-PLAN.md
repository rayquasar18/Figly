    **Query Hooks (frontend/src/hooks/queries/collection-queries.ts):**
    Create all collection TanStack Query hooks:
    - `useCategories()`: useQuery fetching GET /collection/categories
    - `useSeriesByCategory(categorySlug)`: useQuery fetching GET /collection/categories/:slug/series
    - `useItemsBySeries(categorySlug, seriesSlug)`: useInfiniteQuery with cursor pagination, fetching GET /collection/series/:categorySlug/:seriesSlug/items
    - `useItemDetail(itemId)`: useQuery fetching GET /collection/items/:id
    - `useSearchItems(query, filters)`: useInfiniteQuery with cursor, fetching GET /collection/items/search?q=...&categoryId=...&seriesId=..., enabled only when query.length >= 1
    - `useToggleOwned()`: useMutation posting to /collection/items/:id/owned with optimistic update (toggle isOwned, clear isWishlisted if marking owned, adjust ownerCount). Invalidate item detail and item list queries on settle.
    - `useToggleWishlist()`: useMutation posting to /collection/items/:id/wishlist with optimistic update (toggle isWishlisted, clear isOwned if marking wishlist). Invalidate on settle.

    Optimistic update pattern for toggles: follow the exact pattern from interaction-queries.ts (cancel queries, snapshot, setQueryData, rollback on error, invalidate on settled). Update both the item detail query and any item list queries that contain this item.
