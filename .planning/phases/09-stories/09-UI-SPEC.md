## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, story avatar inner padding, progress bar gaps |
| sm | 8px | Story bar horizontal scroll gap, compact element spacing |
| md | 16px | Story bar horizontal padding, story viewer side padding |
| lg | 24px | Section padding, story bar vertical padding top/bottom |
| xl | 32px | Layout gaps between story bar and feed content |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (not used in this phase) |

Exceptions:
- Story avatar ring: 2px gradient border + 2px background gap (total 4px ring thickness) — required for Instagram-style gradient ring rendering
- Story avatar size: 56px (size-14) inner image + 4px ring = 64px total touch target — meets 44px minimum
- "Add story" avatar: 64px (size-16) with dashed border — consistent with story avatar total size

- Story viewer timestamp: `text-xs text-white/70` — secondary info on dark background

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(var(--background))` — white (light) / dark slate (dark) | Story viewer overlay background, page background |
| Secondary (30%) | `hsl(var(--muted))` — light slate | Story avatar placeholder, empty avatar background, story bar border-bottom |
| Accent (10%) | Instagram gradient: `from-yellow-400 via-red-500 to-purple-500` | Unviewed story ring ONLY |
| Destructive | `hsl(var(--destructive))` — red | Delete story confirmation button |

Accent reserved for:
- **Unviewed story gradient ring** — the `bg-gradient-to-tr from-yellow-400 via-red-500 to-purple-500` ring around avatars with unseen stories
- Nothing else in this phase — all other interactive elements use existing primary/muted tokens

**Story-specific colors:**
- Viewed story ring: `bg-muted-foreground/30` — muted gray, clearly distinct from unviewed gradient
- Story viewer background: `bg-black` — full-screen black overlay for immersive viewing
- Story viewer text overlay: `text-white` with shadow for readability on varied backgrounds
- Progress bar track: `bg-white/30` — semi-transparent white on dark overlay
- Progress bar fill: `bg-white` — solid white for active/completed segments
- "Add story" dashed border: `border-muted-foreground/40` — subtle dashed circle

## Interaction Contract

### Story Bar (top of feed)

| Interaction | Behavior |
|-------------|----------|
| Horizontal scroll | Native `overflow-x: auto` with `scroll-snap-type: x mandatory` and `scroll-snap-align: start` on each avatar |
| Tap "+" add button | Opens `CreateStoryFlow` as full-screen overlay |
| Tap user avatar | Opens `StoryViewer` at that user's first unviewed story (or first story if all viewed) |
| Loading state | 5 skeleton circles (size-14) with `animate-pulse` in horizontal row |

### Story Viewer (full-screen overlay)

| Interaction | Behavior |
|-------------|----------|
| Tap right half of screen | Advance to next story in current user's group |
| Tap left half of screen | Go back to previous story in current user's group |
| End of user's stories (auto or tap) | Advance to next user's story group |
| Beginning of user's stories (tap left) | Go to previous user's story group |
| First user, first story, tap left | No action (already at beginning) |
| Last user, last story, advance | Close viewer |
| Tap X button (top-right) | Close viewer |
| Swipe down / press Escape | Close viewer |
| Auto-advance (image) | 5 seconds per image, CSS `@keyframes` linear progress bar animation |
| Auto-advance (video) | Advance after video ends (use `onEnded` event) |
| Progress bars (top) | One bar per story in current user's group; active bar animates fill left-to-right; completed bars are solid white; upcoming bars are `bg-white/30` |
| Mark as viewed | `POST /stories/:id/view` fired when each story is displayed; updates ring color in bar on viewer close |
| Story owner's own viewer | Shows view count overlay at bottom; no "viewed" tracking for own stories |

### Create Story Flow

| Interaction | Behavior |
|-------------|----------|
| Tap "+" on story bar | Opens full-screen overlay with file picker |
| Select image | Preview with "Dang story" (Post story) button |
| Select video | Preview with playback; validate <= 15s client-side; "Dang story" button |
| Tap "Dang story" | Upload media via existing `/media/upload`, then `POST /stories` with mediaId; close flow; invalidate story feed query |
| Tap X / back | Close flow, discard selection |
| Upload in progress | Disable "Dang story" button, show spinner |

### Delete Story (own stories only)

| Interaction | Behavior |
|-------------|----------|
| Long-press or "..." menu on own story in viewer | Show AlertDialog confirmation |
| Confirm delete | `DELETE /stories/:id`; advance to next story or close viewer if last; invalidate story feed query |

## Layout Contract

### Story Bar Placement

```
┌─────────────────────────────┐
│  Header (sticky, h-12)      │  ← existing
├─────────────────────────────┤
│  Story Bar (border-b, py-3) │  ← NEW: horizontal scroll avatars
├─────────────────────────────┤
│  Feed Content               │  ← existing FeedList
│  ...                        │
├─────────────────────────────┤
│  Bottom Nav (fixed)         │  ← existing
└─────────────────────────────┘
```

- Story bar height: auto (content-driven) — approximately 88px (24px top/bottom padding + 64px avatar)
- Story bar border: `border-b` matching existing feed card separators
- Story bar scroll: horizontal, no visible scrollbar (`overflow-x-auto` + webkit scrollbar-hide via utility class)
- Feed page container: `mx-auto max-w-[470px] pb-16` unchanged

### Story Viewer Overlay

```
┌─────────────────────────────┐
│ [progress bars]             │  ← top, 2px height each, 2px gap
│ [avatar] [username] [time] [X] │  ← top overlay row, pt-2
│                             │
│                             │
│    [image / video]          │  ← centered, object-contain, full viewport
│                             │
│                             │
│ [view count - own only]     │  ← bottom overlay, pb-4
└─────────────────────────────┘
```

- Viewer: `fixed inset-0 z-[60] bg-black` — above header (z-50) and bottom nav
- Media: `object-contain w-full h-full` — maintains aspect ratio within black letterbox
- Top overlay: `absolute top-0 inset-x-0 bg-gradient-to-b from-black/50 to-transparent pt-2 px-3`
- Bottom overlay (own stories): `absolute bottom-0 inset-x-0 bg-gradient-to-t from-black/50 to-transparent pb-4 px-3`
- Touch zones: left 40% = previous, right 60% = next (standard Instagram split)

### Create Story Flow

- `fixed inset-0 z-[60] bg-background` — same z-index as viewer
- File input: hidden, triggered by click on upload area
- Preview: full-screen with image/video centered
- Action bar: bottom with "Dang story" primary button + cancel

## Animation Contract

| Animation | Implementation | Duration |
|-----------|---------------|----------|
| Story progress bar fill | CSS `@keyframes progress-fill { from { width: 0% } to { width: 100% } }` with `animation-duration` set dynamically (5s for images, video duration for video) | 5s (image) / dynamic (video) |

| Story viewer exit | `animate-out fade-out` (tailwindcss-animate) | 150ms |

## Accessibility Contract

| Element | Requirement |
|---------|-------------|
| Story bar | `role="list"`, each avatar is `role="listitem"` with `aria-label="{username} story"` |
| Add story button | `aria-label="Them story"` |
| Story viewer | `role="dialog"`, `aria-modal="true"`, `aria-label="Xem story cua {username}"` |
| Close button | `aria-label="Dong"` |
| Progress bars | `role="progressbar"`, `aria-valuenow` / `aria-valuemax` for screen readers |
| Video | `<video>` with no `autoplay` audio — videos play muted by default; user can tap to unmute |
| Keyboard | Escape closes viewer; Left/Right arrows navigate stories (desktop only) |
| Touch targets | All tappable elements >= 44px (story avatars are 64px) |
