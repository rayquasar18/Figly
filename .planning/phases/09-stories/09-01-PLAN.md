**2. Create `backend/src/stories/stories.service.ts`:**

Inject `PrismaService`, `StorageService`, `ModerationService`. Import `STORY_LIMITS` from `@figly/shared`.

Methods:

- **`createStory(userId: string, dto: { mediaId: string })`:**
  - Validate media: `prisma.media.findFirst({ where: { id: dto.mediaId, userId, status: 'COMPLETED' } })`. If not found, throw `BadRequestException('Media khong hop le')`.
  - Calculate `expiresAt = new Date(Date.now() + STORY_LIMITS.expiryHours * 60 * 60 * 1000)`.
  - Create story: `prisma.story.create({ data: { userId, expiresAt, media: { create: { mediaId: dto.mediaId, position: 0 } } } })`.
  - Return the created story.

- **`deleteStory(storyId: string, userId: string)`:**
  - Find story: `prisma.story.findFirst({ where: { id: storyId, userId } })`. If not found, throw `NotFoundException('Story khong ton tai')`.
  - Delete: `prisma.story.delete({ where: { id: storyId } })`.
  - Return `{ success: true }`.

- **`getStoryFeed(userId: string)`:**
  - Get blocked+muted IDs via `Promise.all([this.moderationService.getBlockedUserIds(userId), this.moderationService.getMutedUserIds(userId)])`. Combine into `excludeIds` Set.
  - Query all non-expired stories from self + followed users, excluding blocked/muted/banned:
    ```typescript
    const now = new Date();
    const stories = await this.prisma.story.findMany({
      where: {
        expiresAt: { gt: now },
        user: {
          isBanned: false,
          OR: [
            { id: userId },
            { followers: { some: { followerId: userId } } },
          ],
        },
        ...(excludeIds.length > 0 ? { userId: { notIn: excludeIds } } : {}),
      },
      include: {
        user: {
          select: { id: true, username: true, name: true, avatar: { select: { mediumKey: true } } },
        },
        media: {
          include: { media: { select: { id: true, largeKey: true, mediumKey: true, thumbnailKey: true, mimeType: true } } },
          orderBy: { position: 'asc' },
        },
        views: {
          where: { viewerId: userId },
          select: { id: true },
        },
      },
      orderBy: { createdAt: 'asc' },
    });
    ```
  - Group by user. For each group:
    - Resolve presigned URLs (use `storageService.getPresignedUrl` with `expiresIn: 86400` for 24h matching story TTL). Use `largeKey` for images, `originalKey` for videos (fallback to `largeKey`).
    - For avatar, resolve `mediumKey`.
    - Determine `isViewed` per story (views array length > 0).
    - Determine `hasUnviewed` per group (any story with views.length === 0).
    - Build `StoryGroupResponse` with user info, stories array, hasUnviewed, latestAt (max createdAt).
  - Separate own stories as `myStories` (if any), rest as `followedStories` sorted by `latestAt` desc, unviewed groups first.
  - Return `StoryFeedResponse`.

- **`markViewed(storyId: string, viewerId: string)`:**
  - Check story exists and not expired: `prisma.story.findFirst({ where: { id: storyId, expiresAt: { gt: new Date() } } })`. If not found, throw `NotFoundException('Story khong ton tai hoac da het han')`.
  - Don't track self-views (if story.userId === viewerId, return `{ success: true }` early).
  - Create view with P2002 idempotency:
    ```typescript
    try {
      await this.prisma.storyView.create({ data: { storyId, viewerId } });
    } catch (error: any) {
      if (error.code === 'P2002') return { success: true };
      throw error;
    }
    return { success: true };
    ```

- **`getStoryViewers(storyId: string, userId: string)`:**
  - Find story owned by user: `prisma.story.findFirst({ where: { id: storyId, userId } })`. If not found, throw `NotFoundException('Story khong ton tai')`.
  - Query viewers: `prisma.storyView.findMany({ where: { storyId }, include: { ... user select ... }, orderBy: { viewedAt: 'desc' } })`.
  - Return array of viewer info.

```typescript
export class StoriesCleanupProcessor extends WorkerHost {

    super();
```

```typescript
@Module({
  imports: [
    BullModule.registerQueue({ name: 'story-cleanup' }),
    MediaModule,
    ModerationModule,
  ],
  controllers: [StoriesController],
  providers: [StoriesService, StoriesCleanupProcessor],
  exports: [StoriesService],
})
export class StoriesModule implements OnModuleInit {
  constructor(@Inject('BullQueue_story-cleanup') private cleanupQueue: Queue) {}

  async onModuleInit() {
    // Remove existing repeatable jobs to avoid duplicates on restart
    const repeatableJobs = await this.cleanupQueue.getRepeatableJobs();
    for (const job of repeatableJobs) {
      await this.cleanupQueue.removeRepeatableByKey(job.key);
    }
    // Add repeatable cleanup job every 15 minutes
    await this.cleanupQueue.add('cleanup', {}, {
      repeat: { every: 15 * 60 * 1000 },
    });
  }
}
```
