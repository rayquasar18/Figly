## Component Restoration Contract

This section replaces the standard "new component inventory" since Phase 18 restores existing components.

### Server Component Pages (17 files to restore)

All page.tsx files must follow this contract:

- NO `'use client'` directive
- Export `metadata` (static routes) or `generateMetadata` (dynamic routes with `[params]`)
- `async function` component that renders the existing `*-page-client.tsx` wrapper
- Import client wrapper from relative path (same directory)

| Route Group | Page Count | Metadata Type                                  |
| ----------- | ---------- | ---------------------------------------------- |
| (public)    | 9          | 4 static, 5 generateMetadata                   |
| (app)       | 5          | 5 static                                       |
| (auth)      | 3          | 3 static (2 need Suspense for useSearchParams) |

### UI Component Migration (19 files)

All shadcn/ui components must follow this contract:

- NO `React.forwardRef<>()` wrapper
- `ref?: React.Ref<ElementType>` in props destructuring
- `function ComponentName(...)` declaration (not `const`)
- NO `.displayName` assignment
- Ref passed through to underlying Radix primitive or HTML element

Components to migrate: alert-dialog, avatar, button, card, carousel, checkbox, dialog, dropdown-menu, form, input, label, popover, progress, scroll-area, separator, switch, tabs, textarea, toast.

Already clean (skip): badge, sheet, skeleton, sonner, toaster.

### Import Path Corrections (6 feature files)

All feature components must use barrel imports from `@/features/*` or relative imports within the same feature. Zero imports from deprecated paths:

- `@/stores/*` (use `@/features/auth` barrel)
- `@/hooks/queries/*` (use relative `../hooks/*` within feature)
- `@/components/[domain]/*` (use `@/features/[domain]` barrel)
