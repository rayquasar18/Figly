BEFORE (React 18 pattern — what exists now):

```typescript
const Button = React.forwardRef<HTMLButtonElement, ButtonProps>(
  ({ className, variant, size, asChild = false, ...props }, ref) => {
    const Comp = asChild ? Slot : 'button';
    return (
      <Comp className={cn(buttonVariants({ variant, size, className }))} ref={ref} {...props} />
    );
  },
);
Button.displayName = 'Button';
```

AFTER (React 19 pattern — target state):

```typescript
function Button({
  className,
  variant,
  size,
  asChild = false,
  ref,
  ...props
}: ButtonProps & { ref?: React.Ref<HTMLButtonElement> }) {
  const Comp = asChild ? Slot : 'button';
  return (
    <Comp className={cn(buttonVariants({ variant, size, className }))} ref={ref} {...props} />
  );
}
```

Rules:

1. Remove `React.forwardRef<ElementType, PropsType>(...)` wrapper
2. Convert from `const Component = ...` to `function Component(...)`
3. Move `ref` from second forwardRef argument to props destructuring
4. Add `ref?: React.Ref<ElementType>` to the props type (either inline or via intersection)
5. Remove `.displayName = 'Component'` line
6. Keep all other logic, className, Radix primitive usage identical
