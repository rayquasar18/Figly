Output: All UI components use function declarations with ref as a regular prop instead of React.forwardRef wrapper.

<!-- Migration pattern from research -->

BEFORE (React 18 forwardRef pattern - current code):
```typescript
const Button = React.forwardRef<HTMLButtonElement, ButtonProps>(
  ({ className, variant, size, asChild = false, ...props }, ref) => {
    const Comp = asChild ? Slot : "button"
    return (
      <Comp className={cn(buttonVariants({ variant, size, className }))} ref={ref} {...props} />
    )
  }
)
Button.displayName = "Button"
```

AFTER (React 19 ref-as-prop pattern - target):
```typescript
function Button({
  className,
  variant,
  size,
  asChild = false,
  ref,
  ...props
}: ButtonProps & { ref?: React.Ref<HTMLButtonElement> }) {
  const Comp = asChild ? Slot : "button"
  return (
    <Comp className={cn(buttonVariants({ variant, size, className }))} ref={ref} {...props} />
  )
}
```

For components using React.ComponentProps<"element">:
```typescript
// React 19's ComponentProps already includes ref, so no & { ref? } needed
function Input({ className, type, ref, ...props }: React.ComponentProps<"input">) {
  return <input type={type} className={cn("...", className)} ref={ref} {...props} />
}
```

For Radix primitive wrappers (Dialog, Sheet, etc.):
```typescript
// Before
const DialogContent = React.forwardRef<
  React.ComponentRef<typeof DialogPrimitive.Content>,
  React.ComponentPropsWithoutRef<typeof DialogPrimitive.Content>
>(({ className, children, ...props }, ref) => (
  <DialogPortal>
    <DialogOverlay />
    <DialogPrimitive.Content ref={ref} className={cn("...", className)} {...props}>
      {children}
    </DialogPrimitive.Content>
  </DialogPortal>
))

// After
function DialogContent({
  className,
  children,
  ref,
  ...props
}: React.ComponentPropsWithoutRef<typeof DialogPrimitive.Content> & {
  ref?: React.Ref<React.ComponentRef<typeof DialogPrimitive.Content>>
}) {
  return (
    <DialogPortal>
      <DialogOverlay />
      <DialogPrimitive.Content ref={ref} className={cn("...", className)} {...props}>
        {children}
      </DialogPrimitive.Content>
    </DialogPortal>
  )
}
```

Key rules:
1. Replace `const X = React.forwardRef<...>((props, ref) => ...)` with `function X({ ref, ...props })`.
2. Remove all `X.displayName = "X"` lines (function declarations have name automatically).
3. For components using custom prop types + ref, add `& { ref?: React.Ref<ElementType> }` to the props type.
4. For components using `React.ComponentProps<"element">`, ref is already included in React 19.
5. Keep ALL existing className logic, variant logic, and Radix primitive usage unchanged.
