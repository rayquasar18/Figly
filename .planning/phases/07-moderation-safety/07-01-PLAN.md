    **Critical integration -- block/mute filtering must touch every service that returns user-generated content.**

    **FeedService (feed.module.ts imports ModerationModule):**
    - getFeed: Before query, call `moderationService.getBlockedUserIds(userId)` and `moderationService.getMutedUserIds(userId)`. Combine into excludeFromFeed set. Add `userId: { notIn: excludeFromFeed }` and `user: { isBanned: false }` to where clause.
    - getPublicFeed: Add `user: { isBanned: false }` filter (no block/mute since no viewer).
    - getExploreFeed: Add `user: { isBanned: false }` filter.

    **PostsService (posts.module.ts imports ModerationModule):**
    - getPost: If viewerId provided, fetch blockedIds. If post author is in blockedIds, throw NotFoundException('Bai viet khong ton tai'). Also check `post.user.isBanned`.
    - getUserPosts: Filter out banned users' posts. If viewer provided, check block status between viewer and profile owner -- if blocked, return empty (profile will show 404 anyway).
    - getSavedPosts: Filter `userId: { notIn: blockedIds }` and `user: { isBanned: false }`.
    - getPostsByHashtag: Filter `userId: { notIn: blockedIds }` and `user: { isBanned: false }`.

    **CommentsService (comments.module.ts imports ModerationModule):**
    - getComments: Filter out comments from blocked users: `userId: { notIn: blockedIds }`. Do NOT filter muted users (mute only affects feed per user decision).
    - createComment: Prevent commenting on blocked user's post (check block status between commenter and post author).

    **ProfilesService (profiles.module.ts imports ModerationModule):**
    - getProfile: If viewer provided, check if blocked in either direction. If blocked, throw NotFoundException('Nguoi dung khong ton tai'). If user isBanned, show "Nguoi dung bi cam" response (return profile with isBanned flag, empty post grid).

    **SearchService (search.module.ts imports ModerationModule):**
    - searchUsers: Exclude blocked users from results: `id: { notIn: blockedIds }`, `isBanned: false`.
    - Other search methods: Exclude banned users from results.

    **SocialService (social.module.ts imports ModerationModule):**
    - follow: Check block status before allowing follow. If blocked in either direction, throw BadRequestException('Khong the theo doi nguoi dung nay').
    - getFollowers/getFollowing: Exclude blocked users from lists.

    **NotificationsProcessor:**
    - Before creating notification, check if actor is blocked by recipient. If blocked, skip notification delivery entirely.
    - Do NOT skip for muted users (mute does not affect notifications per user decision).

    **AuthService -- ban check in ALL login paths:**
    - validateUser: After finding user by email, before password check: `if (user.isBanned) throw new ForbiddenException('Tai khoan cua ban da bi cam')`
    - handleGoogleLogin: After finding/creating user: same ban check
    - handleAppleLogin: After finding/creating user: same ban check
    - refreshTokens: After finding user by ID: same ban check. Also delete all refresh tokens for banned user.

    **JwtStrategy:**
    - In validate method, add `isBanned` check: `if (user.isBanned) throw new UnauthorizedException('Tai khoan cua ban da bi cam')` -- this catches active sessions within the 15-min access token window.

    **Module imports:** Each module that uses ModerationService must import ModerationModule. ModerationModule must export ModerationService.

    **Existing test updates:** When adding ModerationService injection to existing services, their test files will need a mock ModerationService provider. Add `{ provide: ModerationService, useValue: { getBlockedUserIds: jest.fn().mockResolvedValue([]), getMutedUserIds: jest.fn().mockResolvedValue([]) } }` to all affected test modules.
