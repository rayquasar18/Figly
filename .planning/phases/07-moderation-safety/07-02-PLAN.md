    - useMutedUsers: infinite query GET /moderation/muted with cursor pagination
    - useBlockStatus: query GET /moderation/block-status/:userId (used in profile to show block state)
    - useMuteStatus: query GET /moderation/mute-status/:userId (used in profile to show mute state)
