## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps in action column, inline padding |
| sm | 8px | Gap between action column icons, compact element spacing |
| md | 16px | Reel overlay padding (author info, action column margins) |
| lg | 24px | Section padding, comments sheet header padding |
| xl | 32px | Layout gaps, action column right margin from edge |
| 2xl | 48px | Major section breaks (not used in this phase) |
| 3xl | 64px | Page-level spacing (not used in this phase) |

Exceptions:
- Action column icon buttons: 40px (size-10) icon with `p-1` (4px) padding = 48px effective touch target — exceeds 44px minimum
- Author info avatar: 32px (size-8) inline with username — compact overlay style matching Story viewer pattern
- Bottom nav icon: 24px (size-6) — unchanged, consistent with existing nav

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `bg-black` | Reel viewer full-screen background, video letterbox |
| Secondary (30%) | `hsl(var(--muted))` | Comments sheet background, profile reels tab area |
| Accent (10%) | `fill-red-500 text-red-500` | Liked heart icon ONLY |
| Destructive | `hsl(var(--destructive))` | Delete reel confirmation button |

Accent reserved for:
- **Liked heart icon** — `fill-red-500 text-red-500` when liked (matches existing PostActions pattern)
- Nothing else in this phase — all other interactive elements use white icons on dark background

**Reel-specific colors:**
- Reel viewer background: `bg-black` — full-screen black for immersive vertical scroll
- Overlay text: `text-white` — all text on reel overlays (author, caption, counts)
- Overlay gradients: `bg-gradient-to-t from-black/60 to-transparent` (bottom), `bg-gradient-to-b from-black/30 to-transparent` (top) — readability on varied video content
- Action column icons: `text-white` — Heart, MessageCircle, Share2, Bookmark (size-7)
- Liked heart: `fill-red-500 text-red-500` — consistent with PostActions
- Bookmarked icon: `fill-white text-white` — consistent with existing bookmarked state pattern
- Mute/unmute icon: `text-white/80` — subtle volume indicator
- Play/pause overlay: `text-white/80 bg-black/20 rounded-full` — center screen tap indicator, fades after 500ms
- Follow button: `border border-white text-white` outline style — does not use accent, matches Instagram Reels pattern
- Loading skeleton: `bg-muted animate-pulse` on `bg-black` background — dark loading state

## Interaction Contract

### Reel Feed (vertical scroll)

| Interaction | Behavior |
|-------------|----------|
| Vertical scroll | CSS `scroll-snap-type: y mandatory` on container; each reel is `scroll-snap-align: start` and `h-[100dvh]` |
| Auto-play | IntersectionObserver (threshold 0.7): play video when visible, pause + reset when not |
| Mute/unmute | Starts muted (browser autoplay policy); tap volume icon (top-right) to toggle; mute state persists across reels via React state |
| Tap center of screen | Toggle play/pause; show centered Play or Pause icon for 500ms then fade out |
| Double-tap | Like/unlike reel; show heart animation (scale-in at tap position, fade out after 600ms) |
| Preload | IntersectionObserver sentinel on next reel loads video `src` before user scrolls to it |
| Infinite scroll | Sentinel div after last reel triggers `fetchNextPage` via useInfiniteQuery; loads 5 reels per page |
| Landscape video | `object-contain` on video element — letterboxed with black bars to maintain 9:16 viewport |
| Memory management | Remove `src` from video elements >1 position from current reel to prevent memory leaks |
| Loading state | Full-viewport skeleton with `animate-pulse` centered `Clapperboard` icon placeholder |

### Reel Action Column (right side)

| Interaction | Behavior |
|-------------|----------|
| Like button | Heart icon; tap to toggle like; filled red when liked; count below |
| Comment button | MessageCircle icon; tap opens ReelCommentsSheet (bottom sheet, half-screen) |
| Share button | Share2 icon; tap copies reel URL to clipboard; shows "Da sao chep lien ket" toast |
| Bookmark button | Bookmark icon; tap to toggle; filled white when bookmarked |

### Reel Author Info (bottom-left)

| Interaction | Behavior |
|-------------|----------|
| Tap avatar | Navigate to user profile |
| Tap username | Navigate to user profile |
| Tap "Theo doi" | Follow user; button disappears after following (or changes to "Dang theo doi") |
| Caption display | Max 2 lines with "...xem them" expand toggle; tap expands to full caption |

### Comments Bottom Sheet

| Interaction | Behavior |
|-------------|----------|
| Open | Slides up from bottom to 50vh height; overlay dims the reel behind |
| Close | Swipe down or tap backdrop to close; video continues playing |
| Scroll | Scrollable comment list with existing threading pattern |
| Add comment | Text input at bottom of sheet with "Dang" (Post) button; same validation as post comments |
| Comment actions | Same as existing post comments (like comment, reply, delete own) |

### Create Reel Flow

| Interaction | Behavior |
|-------------|----------|
| Entry point | "Create" button in bottom nav → option to create post or reel (or extend existing create flow) |
| Select video | File picker filtered to video/* mimetypes |
| Client validation | Max 60s duration (check via video element loadedmetadata); max 100MB file size; reject with error copy |
| Preview | Full-screen video preview with playback controls |
| Caption | Textarea with mention/hashtag support (reuse existing caption logic) |
| Link items | Optional ItemPicker from Phase 4 to link collection items |
| Post | Upload video via `/media/upload`, then `POST /posts` with type='REEL'; show processing state while transcoding |
| Processing | After upload, reel shows "Dang xu ly video..." until transcoding completes; poll media status |
| Cancel | Tap X to discard and return |

### Navigation Changes

| Interaction | Behavior |
|-------------|----------|
| Bottom nav Reels tab | `Clapperboard` icon; navigates to `/reels`; active when `pathname.startsWith('/reels')` |
| Header search icon | `Search` icon button; navigates to `/search`; positioned next to existing DM icon |
| Profile Reels tab | New tab in profile page showing user's reels in grid (reel thumbnail, play icon overlay) |

## Layout Contract

### Reel Feed (full-screen vertical scroll)

```
┌─────────────────────────────┐
│                             │
│    [video - object-contain] │  ← full viewport, bg-black
│                             │
│  [mute icon]          [top] │  ← top-right, volume control
│                             │
│                         [♡] │  ← right-side action column
│                         123 │     vertically centered
│                         [💬]│
│                          45 │
│                         [↗] │
│                         [🔖]│
│                             │
│  [avatar] [username]        │  ← bottom-left author info
│  [Theo doi]                 │     above bottom gradient
│  [Caption text max 2 lines] │
│                             │
└─────────────────────────────┘
│  Bottom Nav (fixed)         │  ← existing, Reels tab active
└─────────────────────────────┘
```

- Feed container: `h-[100dvh] snap-y snap-mandatory overflow-y-scroll` with hidden scrollbar
- Each reel: `h-[100dvh] snap-start relative bg-black`
- Video: `absolute inset-0 w-full h-full object-contain` — letterboxed within black
- Bottom gradient: `absolute inset-x-0 bottom-0 h-[40%] bg-gradient-to-t from-black/60 to-transparent` — ensures text readability
- Top gradient: `absolute inset-x-0 top-0 h-[15%] bg-gradient-to-b from-black/30 to-transparent` — subtle, for mute icon
- Action column: `absolute right-3 bottom-[20%] flex flex-col items-center gap-4` — vertically positioned right side
- Author info: `absolute left-3 bottom-16 max-w-[70%]` — bottom-left, above bottom nav (pb-16 for nav clearance)
- Bottom nav clearance: author info and action column positioned above `pb-16` (64px) to clear fixed bottom nav

## Animation Contract

| Animation | Implementation | Duration |
|-----------|---------------|----------|
| Play/pause icon overlay | Fade in immediately on tap, fade out with `opacity-0 transition-opacity duration-500` | 500ms fade out |
