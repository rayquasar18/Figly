  <action>
    1. Create `frontend/src/hooks/queries/social-queries.ts`:
       - `useFollowMutation()`: useMutation calling POST /social/follow/{targetUserId}.
         - onMutate: cancel queries for ['profile', targetUsername], snapshot previous data, optimistically set isFollowing=true and increment followerCount.
         - onError: rollback to snapshot.
         - onSettled: invalidate ['profile', targetUsername], ['followers'], ['following'] query keys.
         - The mutation function receives an object { userId: string, username: string } so onMutate can target the correct profile query.
       - `useUnfollowMutation()`: Same pattern but POST -> DELETE, isFollowing=false, decrement followerCount.
       - `useFollowers(username: string, search?: string)`: useInfiniteQuery, queryKey: ['followers', username, search]. GET /social/{username}/followers?cursor={pageParam}&search={search}. getNextPageParam: (lastPage) => lastPage.nextCursor. enabled: !!username.
       - `useFollowing(username: string, search?: string)`: Same pattern with ['following', username, search] key and /following endpoint.
       - `useRemoveFollowerMutation()`: useMutation calling DELETE /social/followers/{userId}. onSettled: invalidate ['followers'] queries.

    2. Create `frontend/src/components/social/follow-button.tsx`:
