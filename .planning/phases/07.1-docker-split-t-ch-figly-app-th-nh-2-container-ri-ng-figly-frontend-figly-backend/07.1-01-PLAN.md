<task type="auto">
  <name>Task 2: Build and validate full Docker stack end-to-end</name>
  <files>docker-compose.yml, Dockerfile.frontend, Dockerfile.backend</files>
  <action>
1. Run `docker compose build` to build both figly-frontend and figly-backend images. Both must complete without errors.

2. Run `docker compose up -d` to start all 6 services (postgres, redis, minio, minio-init, backend, frontend).

3. Wait for services to become healthy (up to 60 seconds), then verify:
   - `docker compose ps` shows all services running/healthy
   - Backend is reachable: `curl -f http://localhost:4000/api` (or `/api/health` if that endpoint exists) returns a response
   - Frontend is reachable: `curl -f http://localhost:3000` returns HTML
   - Backend can reach postgres: the Prisma push in entrypoint succeeded (visible in `docker compose logs backend`)
   - No CORS or connection errors in logs: `docker compose logs backend --tail=50` and `docker compose logs frontend --tail=50`

4. Run `docker compose down` to clean up after verification.

If any service fails to start:
- Check `docker compose logs {service}` for the specific error
- Common issues: port conflicts (5432, 6379, 9000, 3000, 4000 already in use), missing env vars
- Fix the root cause in the relevant file before re-attempting

Note: This task may take 2-5 minutes for Docker builds depending on cache state. The build is the primary verification -- if both images build and all services come up healthy, the Docker split is validated.
  </action>
  <verify>
    <automated>docker compose build 2>&1 | tail -5 && docker compose up -d && sleep 15 && docker compose ps && curl -sf http://localhost:4000/api > /dev/null && echo "Backend OK" && curl -sf http://localhost:3000 > /dev/null && echo "Frontend OK" && docker compose down</automated>
  </verify>
  <done>Both Docker images build successfully. All 6 services start and reach healthy state. Frontend responds on port 3000, backend responds on port 4000. Inter-service communication works (backend connects to postgres/redis/minio). docker compose down cleans up.</done>
