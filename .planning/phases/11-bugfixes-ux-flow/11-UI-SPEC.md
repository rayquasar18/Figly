## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, `gap-1` |
| sm | 8px | Compact element spacing, `gap-2` / `p-2` |
| md | 16px | Default element spacing, form field gaps (`space-y-4`), section padding (`px-4`) |
| lg | 24px | Section padding, `py-6` page header padding |
| xl | 32px | Layout gaps, container padding (`p-8`) |
| 2xl | 48px | Sidebar vertical padding (`py-12`) |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Sidebar width: 220px (not a spacing token -- fixed layout dimension per Instagram pattern)
- Bottom nav height: 56px (`h-14`) -- existing, unchanged
- Header height: 56px (`h-14`) -- existing, unchanged
- Nav link touch target: 44px minimum (sidebar link `py-3 px-3` = 48px height)

## Typography

| Role | Size | Weight | Line Height | Tailwind Class |
|------|------|--------|-------------|----------------|
| Body | 14px | 400 (regular) | 1.5 | `text-sm` |
| Label | 14px | 500 (medium) | 1.4 | `text-sm font-medium` |
| Heading | 20px | 700 (bold) | 1.2 | `text-xl font-bold` |
| Sidebar brand | 20px | 700 (bold) | 1.2 | `text-xl font-bold` |

Source: Existing codebase patterns. Page headings use `text-xl font-bold` (explore page, profile page). Form labels use shadcn FormLabel (`text-sm font-medium`). Body text uses Tailwind default `text-sm`. Sidebar nav labels use `text-sm` per Instagram pattern.

Additional rules (from baseline-ui skill):
- Use `text-balance` on headings
- Use `text-pretty` on body paragraphs
- Use `truncate` or `line-clamp` for dense UI
- Never modify `letter-spacing` unless explicitly requested

## Color

| Role | CSS Variable | HSL Value (Light) | Usage |
|------|-------------|-------------------|-------|
| Dominant (60%) | `--background` | 0 0% 100% (white) | Page background, main content area |
| Secondary (30%) | `--card` / `--muted` | 0 0% 100% / 210 40% 96.1% | Cards, sidebar background, nav surfaces |
| Accent (10%) | `--primary` | 222.2 47.4% 11.2% (dark slate) | See reserved list below |
| Destructive | `--destructive` | 0 84.2% 60.2% (red) | Error messages, destructive actions |

Accent reserved for:
- Primary CTA buttons (signup, complete-profile submit)
- Active navigation indicator (sidebar active link `text-foreground` + `font-semibold` + `fill-current` icon)
- Loading spinner border (`border-primary`)
- Focus ring (`ring-ring` which maps to `--ring: 222.2 84% 4.9%`)

Semantic colors in use:
- `text-green-600` -- username availability check (available)
- `text-red-500` -- username availability check (taken)
- `text-muted-foreground` -- secondary/inactive text, inactive nav links
- `bg-destructive/10` with `text-destructive` -- error banners

Dark mode: CSS variables already defined in globals.css `.dark` class. No changes needed this phase (dark mode toggle deferred to Phase 14 FRNT-04).

### Sidebar Specification

```
+---------------------------+
| [Figly logo]              |  <- text-xl font-bold, mb-8, px-3
|                           |
| [Home icon] Trang chu     |  <- nav link, active: font-semibold + fill-current icon
| [Search icon] Tim kiem    |
| [Compass icon] Kham pha   |
| [Clapper icon] Reels      |
| [PlusSquare] Tao moi      |  <- button, not link
| [User icon] Ho so         |
|                           |
|                           |
+---------------------------+
  w-[220px], fixed left-0 top-0, h-dvh, border-r, bg-background
  hidden md:block
```

**Sidebar layout rules:**
- Fixed position, left edge, full viewport height (`h-dvh`, not `h-screen` per baseline-ui)
- Width: 220px
- Z-index: `z-40` (matches existing header and bottom nav)
- Border: right border (`border-r`) using `--border` token
- Background: `bg-background` (matches page surface)
- Padding: `px-3 py-6`
- Brand logo: top of sidebar, `px-3 mb-8 text-xl font-bold`
- Nav links: `flex flex-col gap-1`
- Each link: `flex items-center gap-3 rounded-lg px-3 py-3 text-sm transition-colors`
- Active state: `font-semibold text-foreground` with icon `fill-current`
- Inactive state: `text-muted-foreground hover:bg-muted hover:text-foreground`
- Create button: same styling as nav links but `<button>` element, triggers `useCreatePostStore.open()`
- Icons: `size-6` (24px), from Lucide React

**Sidebar icon mapping:**

| Label | Icon | Route |
|-------|------|-------|
| Trang chu | `Home` | `/` |
| Tim kiem | `Search` | `/search` |
| Kham pha | `Compass` | `/explore` |
| Reels | `Clapperboard` | `/reels` |
| Tao moi | `PlusSquare` | button (create post) |
| Ho so | `User` | `/${username}` |

**Desktop layout with sidebar:**
- Main content area: `md:ml-[220px]` to offset sidebar width
- Header: keep on desktop but remove "Figly" text (it is in the sidebar). Keep search icon in header.
- Bottom nav: `md:hidden` (already set, no change)
- Bottom padding on main: `pb-14 md:pb-0` (already set, no change)
- Reels page: sidebar still visible but header hidden (`hideHeader` logic unchanged)

| State | Visual |
|-------|--------|

## Accessibility Contract

Per baseline-ui skill requirements:

| Rule | Implementation |
|------|---------------|
| Icon-only buttons must have aria-label | Create button in sidebar: `aria-label="Tao bai viet"` |
| Destructive actions use AlertDialog | No destructive actions in this phase |
| Use `h-dvh` not `h-screen` | Sidebar: `h-dvh` |
| Errors shown next to action | Form errors: inline via FormMessage. Server errors: banner above form. |
| No paste blocking | No input restrictions on email, password, username, or display name fields |
| Structural skeletons for loading | FeedSkeleton on explore page (existing) |
| Empty states have one clear next action | Explore empty state shows message only (no action needed -- content is community-generated). Complete-profile IS the clear next action after signup. |
