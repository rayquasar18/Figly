    **1. Create useMessagingSocket hook** (frontend/src/hooks/use-messaging-socket.ts):

    Manages Socket.IO connection lifecycle with JWT cookie auth. Connect to `${NEXT_PUBLIC_API_URL?.replace('/api', '') || 'http://localhost:4000'}/messaging` with `withCredentials: true` and `transports: ['websocket', 'polling']`.

    - Connect when user is authenticated (useAuthStore user is truthy).
    - On 'new_message' event: add message to React Query cache for that conversation's messages query. Update conversation list query cache to move this conversation to top. If conversationId !== activeConversationId in messaging store, increment unread via store.incrementUnread(conversationId). If conversationId === activeConversationId, auto-mark-read by emitting 'mark_read'.
    - On 'message_read' event: update React Query cache to reflect read status.
    - On 'conversation_created' event: invalidate conversations query.
    - Expose: sendMessage(conversationId, content, mediaIds?), markRead(conversationId), socket ref.
    - Cleanup: disconnect on unmount or user logout.

    **2. Create useMessagingStore** (frontend/src/stores/messaging-store.ts):

    Zustand store following existing notification-store pattern:
    ```typescript
    interface MessagingState {
      activeConversationId: string | null;
      unreadCounts: Record<string, number>;
      totalUnread: number;
      setActiveConversation: (id: string | null) => void;
      setUnreadCount: (conversationId: string, count: number) => void;
      incrementUnread: (conversationId: string) => void;
      clearUnread: (conversationId: string) => void;
    }
    ```

    incrementUnread: skip if activeConversationId === conversationId (user is viewing it).
    totalUnread: computed as sum of all unreadCounts values.

    **3. Create messaging React Query hooks** (frontend/src/hooks/queries/messaging-queries.ts):

    Using existing api-client.ts pattern (axios instance with interceptors):

    - useConversations(cursor?): useInfiniteQuery fetching GET /conversations with cursor pagination. Returns ConversationListResponse. queryKey: ['conversations'].
    - useMessages(conversationId, cursor?): useInfiniteQuery fetching GET /conversations/:id/messages with cursor pagination. Returns MessageListResponse. queryKey: ['messages', conversationId]. Enabled only when conversationId is truthy.
    - useUnreadTotal(): useQuery fetching GET /conversations/unread-total. Returns UnreadTotalResponse. queryKey: ['unread-total']. Refetch interval: 30 seconds (fallback for when WebSocket is disconnected).
    - useConversationDetail(conversationId): useQuery fetching GET /conversations/:id.
    - useCreateConversation(): useMutation POST /conversations. On success, invalidate conversations query.
    - useAddParticipant(): useMutation POST /conversations/:id/participants.
    - useLeaveConversation(): useMutation DELETE /conversations/:id.

    **4. Extend api-client.ts** if needed: verify the existing axios instance handles /conversations routes correctly (it should since it already has baseURL and credentials config).
