    **4. Create MessagingGateway** (backend/src/messaging/messaging.gateway.ts):
    @WebSocketGateway({ namespace: '/messaging', cors: { origin: process.env.FRONTEND_URL || 'http://localhost:3000', credentials: true } }). Do NOT specify a port -- attach to same HTTP server.

    Implements OnGatewayConnection, OnGatewayDisconnect. Inject JwtService, PrismaService, MessagesService, ConversationsService, NotificationsGateway (from notifications module, for offline push).

    - private userSockets = new Map<string, Set<string>>()
    - handleConnection(client: Socket): Extract JWT from client.handshake.headers.cookie using cookie-parser logic. Verify with jwtService.verify. Store userId in client.data.userId. Add to userSockets map. Join all conversation rooms: query ConversationParticipant where userId, forEach client.join(`conv:${conversationId}`).
    - handleConnection rejects: disconnect if no token or invalid token.
    - handleDisconnect(client): Remove from userSockets map.
    - @SubscribeMessage('send_message') handleSendMessage(client, { conversationId, content, mediaIds }): Call messagesService.sendMessage. Broadcast 'new_message' to room `conv:${conversationId}`. For each participant not online, enqueue notification via BullMQ (type: MESSAGE).
    - @SubscribeMessage('mark_read') handleMarkRead(client, { conversationId }): Call messagesService.markRead. Broadcast 'message_read' to room `conv:${conversationId}` with { conversationId, userId, readAt }.
    - isUserOnline(userId): Check userSockets.has(userId).
    - emitToUser(userId, event, data): Send to all sockets for userId.
    - joinConversationRoom(userId, conversationId): Find user's sockets and join them to the room. Called by ConversationsService after creating a new conversation.

    Use @nestjs/websockets imports: WebSocketGateway, WebSocketServer, SubscribeMessage, OnGatewayConnection, OnGatewayDisconnect, ConnectedSocket, MessageBody. Server and Socket from socket.io.
